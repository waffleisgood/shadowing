# Korean Waffle · 나의 셰도잉 노트

외국계 회사에서 일하는 한국인을 위한 C1 영어 셰도잉 사이트입니다. 영어 브이로그의 한 장면을 듣고, 따라 말하고, 녹음하면서 실전 표현을 익힙니다.

- 14일 과정: 하루에 영상 1개, 셰도잉 세트 5개(15~25초), 핵심 표현 13~15개
- 영상은 YouTube 공식 임베드로 재생합니다. 영상과 대사의 권리는 각 크리에이터에게 있습니다.
  - Hannah Elise, Jenn Im, Caroline Winkler, Lindsey Rem, Kelsey Simone, Alyssa Lenore, Claudia Sulewski
- 영어 대사는 YouTube 자동 자막을 바탕으로 정리했습니다. 그래서 일부 단어가 실제 발화와 다를 수 있습니다. 한국어 뜻, 발음 팁, 표현 설명, 회사 예문은 학습용으로 새로 썼습니다.
- 사이트 본체는 `shadowing/` 폴더에 있고 주소는 https://koreanwaffle.com/shadowing/ 입니다. 소개 페이지는 `links/` 입니다.
- 학습 완료 기록은 각자의 브라우저에만 저장됩니다. 녹음은 서버로 전송되지 않습니다.
- 글꼴: 그리운 온손글씨(Griun OnHandwriting)
